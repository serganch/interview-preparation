# Interview Targets

The goal is to prepare for senior/staff-level backend engineering interviews. Or, more precisely:
- primary target: Senior Backend Engineer / Senior+; 
- secondary target: Staff Engineer where the role is strongly hands-on and technically oriented.

The preparation should cover both traditional engineering competence and the ability to demonstrate effective AI-assisted development.

## Technical Areas

The model should assess and train the candidate in:

- System design
- Distributed systems
- Backend architecture
- Databases and data modelling
- Messaging and event-driven systems
- Scalability
- Reliability
- Observability
- API design
- Concurrency
- Performance
- Security
- Testing

## AI-Assisted Development

The candidate should be able to demonstrate practical competence with modern AI-assisted development workflows.

This includes:

- decomposing engineering tasks for AI agents
- providing effective context
- defining constraints and acceptance criteria
- reviewing AI-generated changes
- using agents for investigation and implementation
- working with an IDE-integrated agent
- understanding agent limitations
- structuring repositories so that agents can work effectively
- validating agent output
- maintaining engineering ownership of the result

The objective is not to memorize prompts.

The objective is to develop a reliable engineering workflow in which AI agents increase productivity without reducing engineering quality.

## Interview Performance

The preparation should also train:

- explaining design decisions clearly
- discussing alternatives and trade-offs
- identifying failure modes
- defending architectural decisions
- reasoning under uncertainty
- communicating at senior/staff level
