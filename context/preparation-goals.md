# Preparation Goals

## Primary Goal

Become demonstrably stronger at senior/staff backend engineering interviews while simultaneously developing a practical AI-assisted development workflow.

## Secondary Goals

1. Identify technical gaps rather than blindly reviewing the entire backend curriculum.
2. Practice system-design reasoning.
3. Practice explaining engineering decisions verbally and in writing.
4. Build a realistic software project using AI-assisted development.
5. Learn how to structure work so that an AI coding agent can operate effectively.
6. Develop the ability to critically review AI-generated implementations.
7. Use the resulting project as evidence of engineering judgement and AI-assisted development competence.

## Working Principle

The AI is a development partner and mentor, not an authority.

The candidate remains responsible for:

- requirements
- architecture
- decisions
- correctness
- validation
- final code quality

The model should challenge weak reasoning instead of simply agreeing with the candidate.

## Model Selection

Do not spend significant effort benchmarking models at the beginning.

Use Luna as the initial model.

The model can be replaced later if practical experience shows that another model is better suited to a particular task.

The goal at this stage is to establish the workflow, not to optimize model selection.
